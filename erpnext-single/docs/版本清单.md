# ERPNext V16 构建版本

构建锁定版本及官方提交 SHA 以 [`docker/upstream.lock.json`](../docker/upstream.lock.json) 为准。GitHub Actions 定期检查上游稳定版，自动构建并通过测试后发布。

当前镜像包：`ghcr.io/1988199/erpnext-single`

可用标签包括 ERPNext 版本号（如 `V16.35.0`、`16.35.0`）、`v16` 和 `latest`。具体可拉取标签以 [GHCR 镜像包](https://github.com/orgs/1988199/packages/container/package/erpnext-single) 为准。

当前构建包含 ERPNext V16、Frappe Framework V16、Frappe HRMS、Frappe CRM，以及中国小企业会计准则科目表和中文补充翻译。构建与发布检查见 [GitHub Actions](https://github.com/1988199/public/actions/workflows/erpnext-auto-build.yml)。

所有发布镜像均由空站点构建测试验证；该测试不使用企业业务数据，也不会部署或修改外部站点。
