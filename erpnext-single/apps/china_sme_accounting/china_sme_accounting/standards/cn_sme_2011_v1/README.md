# CN-SME-2011-v1 准则包核对记录

## 来源

- 财政部《小企业会计准则——会计科目、主要账务处理和财务报表》：66 个一级会计科目及编号。
- 财政部财会〔2016〕22号《增值税会计处理规定》：将 5403“营业税金及附加”更新为“税金及附加”。

## 与候选网络文件的处理差异

候选文件 `cn_saas_chart_of_accounts.json` 的 66 个一级科目及编号与财政部附录一致，但其明细科目并非完整来源于财政部附录，且存在以下不能原样发布的问题：

1. 10 个增值税明细编码带前导空格。
2. 包含“应交营业税”“排污费”“矿产资源补偿费”等不适合作为 2026 年新建账套默认项的历史税费明细。
3. 将“其他应付款”映射为 ERPNext `Stock Received But Not Billed`，语义不符。
4. 将整个“损益类”设置为 ERPNext `Income` 根类型，会使费用科目错误继承为收入类。
5. 把部分一级科目改为分组并加入企业自定义三级明细，会导致一级科目无法直接记账，也不能再称为财政部 66 个科目的原样基线。

本准则包只保留经核对的 66 个一级科目。为满足 ERPNext 的五类根账户模型，将财政部“损益类”技术性拆分为“损益类－收入”和“损益类－费用”；科目编号和名称不变。企业可以在创建公司后按实际需要增加明细科目。

## 适用限制

本模板只提供建账科目基线，不自动判断企业是否适用《小企业会计准则》，不替代会计人员的专业判断，也不包含税率、期初余额或税务申报配置。
