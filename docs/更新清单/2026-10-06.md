## Twenty 2.45.0 主要变化

- 记录级共享：支持限制默认开放记录、跨角色共享、所有权转移，以及统一的查询和写入权限策略。
- 安全：加强双重验证，防范身份冒用和验证码猜测；修复权限条件组合，增加前端组件校验，并更新安全依赖。
- 工作流与应用：应用工作流使用所属应用权限，支持向成员聊天启动会话；优化工作流列表、命令菜单和校验规则界面。
- 性能与可靠性：降低关联赋值和 ORM 开销，修复迁移失败时连接释放、角色保存及聊天消息持久化问题。

来源：[Twenty 2.45.0 官方 Release](https://github.com/twentyhq/twenty/releases/tag/twenty/v2.45.0)。

## 升级兼容性注意

官方移除了 2.44 上线期间的兼容逻辑及旧 API `submitFormStep`、`answerAgentChatQuestion`，统一使用 `answerToolCall`。使用这些接口的自定义应用需要调整。升级前确认 2.44 的工作区升级已完整执行，尤其是聊天与等待回答的工作流；不要把新镜像启动成功等同于旧业务数据迁移成功。

依据：[官方破坏性变更说明](https://github.com/twentyhq/twenty/pull/27021)。
